# ShadowVault

ShadowVault is a deliberately vulnerable Linux CTF machine designed for
cybersecurity and penetration-testing practice.

## Attack Path

1. Network reconnaissance
2. Web enumeration
3. Hidden directories
4. Information disclosure
5. Credential discovery
6. SSH foothold
7. Privilege escalation through a writable root-executed script
8. Root access

## Environment

- Target: Ubuntu Server
- Attacker: Kali Linux
- Virtualization: VirtualBox
- Web Server: Apache
- Backend: PHP
- SSH: OpenSSH
- Database: MariaDB

## Intended Learning

- Nmap
- Gobuster
- Web enumeration
- Credential discovery
- Linux file permissions
- SSH
- SUID
- Systemd services and timers
- Privilege escalation
- CTF methodology

## Disclaimer

ShadowVault is intentionally vulnerable and should only be used
in an isolated, authorized lab environment.
